# Госуслуги PWA

Цифровые документы и государственные сервисы — Progressive Web App.

## 🚀 Запуск

1. Загрузите файлы в репозиторий GitHub
2. Включите GitHub Pages: Settings → Pages → Branch: main
3. Откройте ссылку в браузере телефона

## 📱 Установка на домашний экран

### iOS (Safari):
1. Откройте сайт в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
3. Выберите «На экран «Домой»»

### Android (Chrome):
1. Откройте сайт в Chrome
2. Нажмите меню (⋮)
3. Выберите «Добавить на главный экран»

## 📂 Структура

- `index.html` — основной HTML
- `style.css` — стили
- `app.js` — логика приложения
- `manifest.json` — PWA манифест
- `sw.js` — Service Worker для оффлайн работы
- `icons/` — иконки приложения
